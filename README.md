# ClubOS — نادي الحاسبات

واجهة Frontend عربية RTL لإدارة نادي الحاسبات، بدون Backend.

## هذه النسخة
- هوية لونية مستوحاة من ألوان/طابع جامعة أم القرى بدون استخدام شعار الجامعة.
- إضافة رئاسة النادي وقيادات اللجان بالأسماء المعتمدة.
- Dashboard + فعاليات + أعضاء + مهام + جودة وحياة + علاقات عامة + تسويق + مسابقات وأنشطة + تقارير.
- التخزين محليًا عبر localStorage داخل المتصفح.
- وضع فاتح/داكن.

## التشغيل
افتح `index.html` مباشرة في المتصفح.

> ملاحظة: لا توجد مصادقة أو مزامنة أو قاعدة بيانات حقيقية في هذه النسخة لأنها Frontend فقط.
